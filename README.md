# 🕊️ 身后名 Legacy Clean

> 连续 N 天未使用浏览器时，自动清空浏览历史，并伪造一批"积极正面"的浏览记录——替你在身后守住名声。

一个开源的浏览器扩展（Manifest V3，支持 Chrome / Edge），灵感来自 Opera GX 的 *Fake My History* 功能，但做了更安全的改进。

## ✨ 功能特性

| 特性 | 说明 |
|---|---|
| 🕒 活跃检测 | 监听真实使用行为（开标签、切标签、浏览网页都会刷新计时），比纯计时更准 |
| ⚰️ 死亡开关 | 连续 N 天未使用（默认 14 天，可调 1~365 天）自动触发 |
| 🛡️ 干跑模式（默认） | 只生成"本可清除多少条"报告，**不真删历史**，防误伤 |
| 📝 伪造积极记录 | **1080 个真实网站**、8 大领域（新闻/游戏/学习/健康/购物/生活/政务公益/影音），按领域随机抽选，可自定义条数 |
| 🇨🇳 国内网络适配 | 开关一键过滤国内无法访问的外网站，避免"真人没梯子却访问了被墙网站"的穿帮 |
| ✅ 写入后验证 | 触发后立即回查历史，报告"实际写入 N 条、验证存在 N 条" |
| 🧪 一键测试 | 「假装我已死」按钮立即模拟触发，不用真等 N 天 |
| 📊 实时状态 | 面板显示"已静默 X 天"、上次触发时间与结果 |

## 📦 安装

1. 下载源码（或解压 zip）到本地文件夹
2. 打开 Edge 地址栏输入 `edge://extensions`（Chrome 输 `chrome://extensions`）
3. 打开左下角 **「开发人员模式」**
4. 点 **「加载解压缩的扩展」**，选择本项目文件夹
5. 点工具栏的 🕊️ 图标打开控制面板

> 首次加载会提示"读取和更改浏览记录"权限，这是功能必需，请允许。

## ⚙️ 使用

- **保持干跑模式开启**，点「假装我已死」测试——它会告诉你本可清除多少条历史，但不会真删
- 确认行为符合预期后，再关闭干跑开关启用真实模式
- 触发天数、各领域伪造条数、国内适配、自定义网址都可以在面板中设置

## ⚠️ 已知限制

- `chrome.history.addUrl` 的 `visitTime` 参数会被浏览器忽略，伪造记录的访问时间一律为触发时刻（这是 Chrome/Edge 扩展 API 的限制，Opera 因为是浏览器本体才能写入过去时间）
- 同一 URL 在历史中会合并显示，因此每条伪造网址写入一条记录
- 清除统计上限 10000 条历史（`history.search` 单次返回上限）

## 🔒 隐私说明

- 所有数据（最后活跃时间、触发报告）仅存储在**浏览器本地**（`chrome.storage.local`），不上传任何服务器
- 干跑模式下不会修改你的任何浏览历史
- 完整源码可审计，无第三方依赖
